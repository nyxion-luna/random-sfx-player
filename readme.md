# rsp

## what is this?

this program randomly plays the provided sound effect like those '1 hour of silence occasionally interrupted by [insert sfx or meme]' videos.

## how can i use it?

you install the command and run `rsp filepath`. you can provide a --volume flag, such as `rsp filepath --volume 200` to double the volume or make the sound playing be synchronous by running `rsp filepath --blocking`

## why make this?

i found one of this videos and thought that it was way easier to just write code to make it modular. plus, the video i analyzed to select timings for this code actually had a pattern so it wasn't really random.
